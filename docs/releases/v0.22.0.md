# Codemble v0.22.0 — luminous galaxies and living solar systems

v0.22.0 makes the entire project readable before learning begins. Free Explore
keeps every system colourful and luminous, while amber remains reserved for
understanding proved through checks.

## A galaxy that stays alive

- Hovering or selecting a system no longer turns unrelated Explore systems
  black.
- Brighter layered sky light, route contrast, language atmosphere, and larger
  worlds keep the full project legible without erasing depth.
- Guided Learning can still soften distant context when focus is useful; it
  never removes parser-owned structure.

## Every module becomes a solar system

- The parser-owned module anchor is now a central Sun rather than an anonymous
  planet.
- Every function and class is named in the scene and placed in a parser-owned
  call orbit; call roots remain distinct from direct calls, and the outer drift
  says when no proven call path exists.
- A nearby-systems console lists parser-owned inbound and outbound imports and
  opens the connected system directly, preserving certain versus possible
  evidence.

## Nine kinds of worlds

Python, JavaScript, TypeScript, Go, Java, Rust, C#, Ruby, and PHP each receive a
deterministic world profile: distinct terrain, mineral bands, atmosphere,
shimmer, tilt, and motion derived from the parser-owned language. Reduced-
motion mode removes animation while preserving visibility.

## Truth boundary

Colour and scenery do not claim understanding. Amber still means passed checks
only. The language style encodes one existing parser fact, possible routes stay
possible, and no inferred structure, XP, extra quest, or free-flight camera was
added.

# Codemble v0.23.0 — deeper worlds, closer study

Codemble v0.23.0 turns the Galaxy and System views into a richer, game-like
expedition while preserving parser-owned truth. Seeded ocean, ice, rocky, and
banded worlds now carry relief, cloud cover, thin atmospheres, a granular Sun,
and layered nebula scenery. Study keeps the selected world beside its source
evidence, and reduced-motion users receive the same content without the travel.

The learning contract is unchanged: parser evidence owns every system, world,
route, role, and journey; possible relationships stay visibly possible; and
amber appears only after a learner passes graph-derived checks.

This release also includes the local share-artifact compiler, exact disclosure
preview, capability lifecycle, encrypted persistence, standalone delivery
reference, backup and restore machinery, and failure relay developed for M20.
The compiler and exact disclosure preview are connected locally in the product;
they create no link and make no outbound request. Capability persistence,
standalone delivery, backup, and operations remain disconnected from that local
flow. v0.23.0 adds no upload, provider, account, or public cloud route, and it
makes no claim that operational deletion or media erasure has been proven.
Independent deployment receipts remain mandatory before public sharing can be
connected.

Compatibility updates admit cryptography 50, tree-sitter-go 0.25,
tree-sitter-rust 0.24, and JetBrains Mono 5.3 after focused and full-suite
verification. Public captures, installation commands, release artifacts, and
checksums now derive from the same v0.23.0 release manifest.

## Improved

- Python namespace resolution and graph-check option generation avoid repeated
  whole-project scans while preserving parser meaning and pinned answers.
- Scheduled writer and operator maintenance now fails visibly when its required
  operation lock is missing or is not a regular file, allowing the existing
  alert relay to observe the failed service start.

## Known limits

- Public share delivery remains disconnected pending the M20 operational gate.
- The original unaided learner-acceptance issue remains open; automated evidence
  does not substitute for learner testing.
- The 3D Galaxy requires WebGL. The complete Canvas 2D Map remains available
  when WebGL is unavailable.
